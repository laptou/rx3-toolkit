# Hector

With this module on, the TRANS Beat FX is renamed HECTOR. Turning it ON
shows the hector sprite. Turning it OFF hides the sprite. The audio stays
dry: TRANS does not run. BEAT and TIME still edit TRANS and do not change the
picture.

LEVEL/DEPTH is the size. Full depth is about 0.9× the height of one waveform
strip. Depth at zero hides the sprite.

The channel places it, centred on the waveform:

- CH1, over track 1
- CH2, over track 2
- Master, in the middle, on the seam between the two strips

The sprite is `RX3_SPRITES/hector.rx3spr`, the same pack the sprites tools
write. If that file is missing, TRANS stays stock.

This mod is not for use with the sprites mod or with Charizard.
